SecureAttachment supports the following standard file types:


| Type | API | Notes |
| --- | --- | --- |
| JPEG | Images	|  |
| PNG8 | Images |  |	
| PNG24 | Images |  |	
| PDF | Files | Multi-page and embedded images supported |
| GIF | Images |  |	
| BMP | Images |  | 	
| CSV | N/A | Native - no API required |
| Word Document (.doc) | N/A | Native - no API required |
| WEBP | Images |  |	
| RAW | Images |  |	
| TIFF | Files |  |	
| ICO | Images |  |
