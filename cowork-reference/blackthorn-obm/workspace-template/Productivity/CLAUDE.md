# Productivity

Task tracking for your onboarding portfolio.

## TASKS.md Format

```
## Active
- [ ] **[Task title]** - [context], for [customer], due [date if known]

## Waiting On
- [ ] **Waiting: [what]** - from [customer/contact], since [date]

## Done
- [x] **[Task title]** - completed [date]
```

Keep Active short and honest. If there are more than 8-10 items, something is in the wrong bucket.
